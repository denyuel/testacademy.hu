# TestAcademy Design System

## Visual Identity
TestAcademy is a premium mentoring platform for Senior QA Engineers. The design is modern, dark-themed, and energetic.

## Core Tokens
- **Background:** Slate 900 (#0f172a)
- **Primary Color:** Blue 500 (#3b82f6)
- **Secondary Color:** Indigo 600 (#4f46e5)
- **Typography:** Sans-serif (Outfit or Inter), heavily using **Black Italic** weights for headings.
- **Corner Radius:** Large (24px to 40px) for a soft yet professional look.
- **Effects:** Glassmorphism, subtle blue glows (0 0 20px blue/20), and high-contrast text.

## UI Components
- **Cards:** Rounded-3xl, subtle borders, scale on hover.
- **Buttons:** Bold, uppercase, tracking-widest, often with arrows (→).
- **Modals:** Blur background (backdrop-blur-md), fixed positioning, high z-index.

## Language
- Bilingual support (HU/EN) with a toggle.
